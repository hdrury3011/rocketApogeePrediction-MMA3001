# Cruise-Phase Apogee Prediction

Project for MMA3001 (Numerical Methods and Machine Learning) 2026.

Predicts the apogee of a rocket during the unpowered (coast) phase after motor
burnout, using CFD-derived drag coefficients that depend on Mach number and
airbrake (flap) extension. The project compares numerical integrators against
an analytical solution, calibrates the unknown rocket mass against a measured
apogee, and checks the airbrake prediction against a second measured apogee.

## Engineering problem

| | |
|---|---|
| **Inputs** | Burnout speed (m/s), burnout altitude (m), rocket mass (kg), reference area (m^2), flap extension (0-100 %, constant or a function of time), CFD drag table C_D(Mach, flap) |
| **Outputs** | Apogee altitude (m) and time to apogee after burnout (s); calibrated mass (kg); flap setting or deployment delay that reproduces a measured apogee |
| **Model** | Vertical flight, no wind, zero angle of attack: `dv/dt = -g - rho(h) C_D(Mach, flap) S v|v| / (2m)`, ISA troposphere |
| **Supplied data** | Burnout 280 m/s at 1800 ft; apogee 3450 m without airbrakes and 11000 ft with airbrakes; 6 in reference diameter (see `src/config.py`) |
| **Not supplied** | Mass (calibrated from the 3450 m apogee), the airbrake deployment schedule |

Invalid inputs (negative mass or speed, flap outside 0-100 %, altitude outside
the ISA troposphere, impossible calibration targets) raise `ValueError`.

## Repository layout

```
src/
  apogee.py             analytical benchmark (constant rho and C_D)
  integrators.py        Euler and RK4 steps, integration to apogee
  atmosphere.py         ISA troposphere, constant-density atmosphere
  drag.py               C_D(Mach, flap) table loader and interpolation
  coast.py              coast equations of motion and apogee prediction
  calibration.py        bisection, mass calibration, flap-for-apogee
  center_of_pressure.py centre of pressure from the CFD forces and moments
  config.py             known inputs and constants
  main.py               runs the whole study, writes figures and results
tests/                  pytest suite
docs/results.md         numerical results generated by main.py
docs/figures/           figures generated by main.py
```

## Setup

```
python -m venv .venv
.venv\Scripts\Activate.ps1          # Windows PowerShell
pip install -r requirements.txt
```

## Data

The CFD data set (`project_data_set.csv`) is not stored in this repository
(`data/` is in `.gitignore`). Put it in `data/` or pass its location to the
scripts. Tests that need it are skipped if it is missing.

## Run

```
python src/main.py --data data/project_data_set.csv
```

This writes `docs/results.md` and the figures in `docs/figures/`.
Use `--no-plots` to skip the figures.

## Tests

```
pytest
```

Set `APOGEE_DATA` to the csv path to run the tests that need the data set.

## Documentation

HTML documentation of the source code is generated with pdoc:

set PYTHONPATH=src                  # PowerShell: $env:PYTHONPATH = "src"
pdoc -o docs/api apogee atmosphere calibration center_of_pressure coast config drag integrators main
